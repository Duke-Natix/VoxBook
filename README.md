# VoxBook

**VoxBook turns PDF and text files into a personal audiobook on Android.**

It combines local AI narration, selectable narrator voices, saved voice clones, PDF page navigation, a persistent library, background playback with Android media controls, and an adaptive interface in one focused reader app.

## Highlights

- Open PDF and TXT files directly on Android
- Keep the original PDF page visible while listening
- Start narration from a selected PDF page or restart from the beginning
- 4 male and 4 female German AI narrator profiles
- Record, name, save, reuse, and delete personal voice profiles
- Native background narration with notification / lock-screen media controls
- Reading-position memory and persistent PDF collection
- German and English support
- Adjustable appearance, including dynamic mood-based accent colors
- In-app update checks for sideloaded builds
- Integrated Help section explaining the app and its controls
- Local document and voice processing; model downloads are cached for offline use

## Privacy

VoxBook is designed to process documents and saved voice profiles locally on the device. Internet access is used for model downloads, update checks, and downloading new app versions. See [PRIVACY.md](PRIVACY.md) for details.
